# Sistema de Cadastro de Produtos em Java

Projeto acadêmico desenvolvido em Java com interface gráfica utilizando Swing. O sistema permite cadastrar, alterar e consultar produtos e categorias por meio de um menu interativo.

## Tecnologias Utilizadas

* Java
* Java Swing
* Maven
* Programação Orientada a Objetos
* Collections Framework

## Estrutura do Projeto

```text
src/main/java/br/com/fiap/produtos
├── model
├── repositorio
├── view
└── Main.java
```

## Funcionalidades

* Cadastro de categorias
* Cadastro de produtos
* Alteração de produtos
* Consulta de produto por ID
* Consulta de produtos por categoria
* Interface gráfica desktop
* Encerramento do sistema

## Conceitos Aplicados

* Orientação a Objetos
* Separação de responsabilidades
* Organização em camadas
* Manipulação de listas em memória
* Interface gráfica com Swing

## Como Executar

### Pré-requisitos

* Java JDK instalado
* Maven instalado

### Rodar projeto

```bash
mvn compile
mvn exec:java
```

Ou execute a classe `Main.java` pela IDE.
